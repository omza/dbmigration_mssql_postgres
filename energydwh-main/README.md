# EnergyDWH

In diesem Repository werden alle Datenbankobjekte aus unseren Datawarehouse(s) und deren Änderungen automatisch nachvollzogen.
Folgende Objekte werden einmal täglich gesichert:
- Stored Procedures
- Functions
- Views
- Tables
- Foreign Keys
- Indizes

Das genaue Verfahren wird [hier](https://stwnor.atlassian.net/wiki/x/BABXcQ) beschrieben.
